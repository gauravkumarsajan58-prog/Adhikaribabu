# AdhikariBabu

Professional mobile-first starter website built with Next.js + Tailwind CSS.

## Run locally
1. Install Node.js 18+
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:3000`

## Deploy on Vercel
Push this folder to GitHub, then import the repository in Vercel.
No database is required for this starter homepage.
